# Web Application

This directory is intended to contain the web application for the CrypPhish-AI framework.

---

## Purpose

The web application provides an interactive interface that allows users to:

- Upload an email file (.eml)
- Enter email content manually
- Perform phishing email detection using the trained Machine Learning model
- Store metadata of legitimate emails on the Ethereum blockchain
- Display prediction results in real time

---
