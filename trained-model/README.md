# Trained Models

This directory is reserved for storing trained Machine Learning models used by the CrypPhish-AI framework.

---

## Planned Contents

Future versions of this project may include:

- Trained Logistic Regression model
- Random Forest model
- Support Vector Machine (SVM) model
- LSTM model
- TF-IDF vectorizer
- Serialized model files (.pkl)

---

## Purpose

The purpose of this directory is to store trained models that can be loaded by the Streamlit application for phishing email prediction.

At the current stage of this repository, trained model files are not included.

---

## Note

Model files are intentionally omitted from this repository because they can be regenerated using the provided datasets and training scripts.
