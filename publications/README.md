## Research Contribution

These two publications present the scientific foundation of this repository.

- The first publication introduces a hybrid phishing email detection framework combining Artificial Intelligence and cryptographic protocols.

- The second publication extends the framework by integrating Ethereum blockchain and smart contracts to provide secure communication, data integrity, and immutable email verification.

The complete implementation presented in these publications is available throughout this GitHub repository.
