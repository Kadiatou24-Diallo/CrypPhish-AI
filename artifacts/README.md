# Model Artifacts

This directory is intended to store the trained Machine Learning artifacts used by the CrypPhish-AI application.

## Expected Files

- best_model.pkl (Scikit-learn model)
- best_model.keras (LSTM model, if applicable)
- tfidf_vectorizer.pkl
- label_mapping.json
- lstm_tokenizer.json (for LSTM models)

## Purpose

These files are loaded by the Streamlit application to perform phishing email detection.

## Note

The trained model artifacts are not included in this public repository.

They can be regenerated by following the Machine Learning training pipeline described in the project documentation.
