# Project Overview

## Introduction

CrypPhish-AI is a research project developed as part of my M.Tech in Information Security and Cyber Forensics.

The project proposes a hybrid framework that combines Artificial Intelligence (AI) and Ethereum blockchain technology to improve phishing email detection and secure communication.

Traditional phishing detection systems rely only on machine learning models, while blockchain-based solutions often lack intelligent email classification. CrypPhish-AI combines both technologies to provide accurate phishing detection together with secure and tamper-resistant email verification.

---

## Problem Statement

Phishing attacks remain one of the most common cyber threats, causing financial loss, identity theft, and unauthorized access to sensitive information.

Existing solutions often suffer from:

- High false positive and false negative rates
- Lack of secure verification for legitimate emails
- Limited traceability
- Weak protection against email tampering

---

## Project Objectives

The objectives of CrypPhish-AI are:

- Detect phishing emails using Machine Learning.
- Improve classification accuracy.
- Secure legitimate email records using Ethereum blockchain.
- Store hashed email metadata through smart contracts.
- Enhance trust, integrity, and secure communication.

---

## Project Contributions

This project provides:

- A Machine Learning-based phishing email detection system.
- Ethereum smart contract integration.
- SHA-256 hashing for email verification.
- A Streamlit web application.
- Experimental evaluation using multiple ML algorithms.
- Research contributions published in IEEE conferences.
