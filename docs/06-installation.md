# Installation Guide

## Requirements

Before running the project, install the following software:

- Python 3.x
- Git
- Ganache
- Node.js
- Visual Studio Code
- Jupyter Notebook

---

## Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/CrypPhish-AI.git
```

---

## Navigate to the Project

```bash
cd CrypPhish-AI
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Start Ganache

Launch Ganache and create a local Ethereum blockchain.

---

## Deploy the Smart Contract

Deploy the EmailRegistry smart contract to the local Ethereum network.

---

## Run the Application

```bash
streamlit run source-code/app.py
```

The application will be available at:

```
http://localhost:8501
```
