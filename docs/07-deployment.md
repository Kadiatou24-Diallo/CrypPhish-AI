
# Deployment Guide

## Overview

This document explains how to deploy the CrypPhish-AI framework on a local development environment.

---

## Deployment Workflow

The deployment consists of the following steps:

1. Clone the repository.
2. Install Python dependencies.
3. Launch Ganache.
4. Deploy the EmailRegistry smart contract.
5. Configure the blockchain connection.
6. Start the Streamlit application.
7. Test phishing email detection.

---

## Components

- Machine Learning Model
- Streamlit Web Application
- Ethereum Blockchain
- Ganache Local Network
- Solidity Smart Contract
- Web3.py

---

## Deployment Verification

The deployment is considered successful when:

- The Streamlit application starts correctly.
- The Machine Learning model loads successfully.
- The smart contract connects to Ganache.
- Legitimate emails are stored on the blockchain.
- Phishing emails are correctly detected.
