# Blockchain Module

This directory contains all blockchain-related components used in the CrypPhish-AI framework.

## Contents

### EmailRegistry.sol

The Solidity smart contract responsible for securely storing the SHA-256 hash of legitimate emails on the Ethereum blockchain.

Main functions include:

- Register a verified email hash
- Verify whether an email already exists
- Prevent duplicate registrations
- Provide immutable blockchain storage

---

### EmailRegistry_Deployment.json

Contains the deployment information of the smart contract, including:

- Contract Address
- ABI
- Network ID
- Deployment transaction details

This file is used by the Python application to communicate with the deployed smart contract.

---

### compiled_code.json

Contains the compiled Solidity smart contract generated by the Solidity compiler.

It includes:

- ABI (Application Binary Interface)
- Bytecode
- Metadata

The compiled output is required before deploying the smart contract to Ethereum.

---

## Blockchain Workflow

The blockchain module performs the following operations:

1. Receive the SHA-256 hash generated from a legitimate email.
2. Connect to the local Ethereum blockchain (Ganache).
3. Execute the EmailRegistry smart contract.
4. Store the email hash on-chain.
5. Allow future verification of stored emails.

---

## Purpose

The blockchain layer guarantees:

- Integrity
- Immutability
- Traceability
- Secure verification of legitimate emails

without storing the original email content on the blockchain.
