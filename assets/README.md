# Assets

This directory contains all visual assets used in the CrypPhish-AI project.

## Folder Structure

```
assets/
├── architecture/
│   └── System architecture diagrams
│
├── diagrams/
│   └── Workflow and blockchain integration diagrams
│
└── figures/
    └── Experimental results, ROC curves, confusion matrices, screenshots
```

## Description

### architecture/
Contains the overall system architecture and high-level design diagrams.

### diagrams/
Contains workflow diagrams illustrating the interaction between Artificial Intelligence and Ethereum blockchain.

### figures/
Contains figures used in the M.Tech thesis and project documentation, including:

- Machine Learning performance results
- ROC Curves
- Confusion Matrices
- Blockchain screenshots
- Streamlit interface screenshots
- Experimental figures

These assets are referenced throughout the documentation and README files.
