## Demonstration Workflow

The screenshots illustrate the complete workflow of the proposed framework:

1. Launch the Streamlit application.
2. Enter or upload an email.
3. The Machine Learning model classifies the email.
4. Phishing emails are flagged.
5. Legitimate emails are securely stored on the Ethereum blockchain.
6. Ganache records the blockchain transaction and block creation.
