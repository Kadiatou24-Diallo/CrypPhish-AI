# Source Code

This directory contains the complete source code of the CrypPhish-AI application.

## Files

| File | Description |
|------|-------------|
| app.py | Main Streamlit application implementing phishing email detection and blockchain integration |

---

## Application Features

- Email phishing detection using Machine Learning
- TF-IDF feature extraction
- Email upload (.eml and .txt)
- SHA-256 email hashing
- Ethereum blockchain integration
- Smart contract interaction
- Blockchain email verification
- Confidence score visualization
- Interactive Streamlit user interface

---

## Technologies

- Python
- Streamlit
- Scikit-learn
- Web3.py
- Solidity
- Ethereum
- Ganache

---

## Run the Application

```bash
streamlit run app.py
```

The application will start at:

```
http://localhost:8501
```

## Purpose

This folder contains the complete implementation of the CrypPhish-AI web application developed for phishing email detection and secure blockchain-based email verification.
